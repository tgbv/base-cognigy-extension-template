## Setup

```
# clone the base extension template
git clone https://github.com/tgbv/base-cognigy-extension-template

# installs base dependencies
npm ci

# for windows
npm run build-windows

# for mac/linux
npm run build
```

**For Windows users:** In case powershell is complaining when running NPM: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
